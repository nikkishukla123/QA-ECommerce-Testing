# E-Commerce Website Testing Project

## Project Overview
This project demonstrates manual testing of an e-commerce web application similar to Amazon/Flipkart. The scope covers user registration, login, product search, product details, add to cart, checkout, payment validation, order confirmation, and regression testing.

## Modules Tested
- User Registration
- User Login and Logout
- Product Search
- Product Listing and Filters
- Product Details Page
- Add to Cart
- Cart Management
- Checkout
- Address and Payment Validation
- Order Confirmation

## Testing Performed
- Functional Testing
- Regression Testing
- Smoke Testing
- Negative Testing
- UI Validation
- Boundary Value Testing

## Deliverables
- Test Plan
- 55 Manual Test Cases
- Bug Report
- Mock JIRA Defect Tickets
- Requirement Traceability Matrix
- Test Summary Dashboard

## Tools Used
- Microsoft Excel
- JIRA / Mock JIRA
- Browser DevTools

## Resume Points
- Created and executed 55 manual test cases for core e-commerce workflows including registration, login, search, add to cart, and checkout.
- Identified, documented, and prioritized defects using a mock JIRA defect tracking workflow.
- Performed functional, regression, smoke, and negative testing to validate critical user journeys.
- Prepared test plan, test cases, bug reports, RTM, and execution summary for a complete QA project portfolio.

## Interview Explanation
I tested an e-commerce website similar to Amazon/Flipkart. I prepared a test plan, wrote 55 test cases, executed them across major modules, and documented bugs with severity, priority, steps to reproduce, expected result, and actual result. I also performed regression testing after bug fixes to ensure existing functionality was not impacted.
